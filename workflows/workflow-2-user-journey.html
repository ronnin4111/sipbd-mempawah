Klik "Login Admin" di sidebar, masukkan password (diskan2026). Status admin aktif ditampilkan di sidebar
Password Gate Session Browser
2
Kelola Data Pembudidaya (CRUD)
Tambah record baru, edit inline, hapus record. Tombol kunci admin muncul di tabel data
Create Update Delete Batch Delete

Upload file Excel .xlsx, preview data + validasi, lalu import ke database. Mode replace atau merge

Mengunduh workbook Excel lengkap: Data Pembudidaya, Produksi/Kecamatan, Target, Tren, RTP, Harga

Disagregasi Data Agregat
Wizard 3 langkah: pilih data agregat, preview distribusi proporsional ke pembudidaya, simpan ke database

Edit matriks harga ikan (Pembesaran Rp/Kg dan Pembenihan Rp/Ekor). Import harga dari Excel
Inline Edit Batch Update Excel Import

Atur Visibilitas Kolom
Toggle kolom tabel yang ditampilkan. Pengaturan tersimpan di database (sync antar perangkat)
