Import Pipeline
Excel → Preview → Database
1. Upload File Excel
Admin upload file .xlsx melalui dialog import. File dikirim via FormData ke server
FormData.xlsx
2. Server-Side Parsing
XLSX library parse file di server. Normalisasi container type alias, fix KUSUKA 16-digit precision
SheetJSNormalization
3. Preview & Validasi
Data dipreview di tabel. Validasi field wajib, auto-fill kecamatan/desa, cek duplikat farmerId
PreviewValidation
4. Pilih Mode Import
Replace (hapus semua lalu insert) atau Merge (upsert berdasarkan farmerId + year + fishType)
ReplaceMerge
5. Batch Insert ke DB
Prisma createMany batch insert. Auto-generate farmerId (djb2 hash). Cache di-invalidate
PrismaBatchCache Invalidate

Stats Aggregation Engine
Database → 20+ Agregasi → Frontend
1. Filter Parameters
7 dimensi filter (years[], kecamatan[], desa[], fishType[], containerType[], businessType[], search)
Query ParamsMulti-Filter
2. Prisma Aggregation
groupBy queries: produksi per fishType, per kecamatan, per tahun, per container. Cross-tab queries
groupBysumcount
3. Compute Derived Stats
Trend 5 tahun (% change), target vs realisasi, unique farmers/groups, KUSUKA counts, price calculations
Trend %Cross-TabDedup
4. Cache & Deliver
React Query cache (auto-refetch on filter change). Single /stats endpoint serves all views
React QueryAuto-Refresh
5. Frontend Rendering
Charts (Recharts), Tables (TanStack), Cards, Map markers. Semua terupdate real-time saat filter berubah
RechartsTanStackLeaflet

Export Pipeline
Database → Excel/PDF → Download
1. Export Excel (6 Sheet)
Server-side: Data Pembudidaya, Produksi/Kecamatan, Target/Realisasi, Tren 5 Tahun, RTP, Harga Komoditas
xlsx6 SheetsPassword Required
2. Export PDF Client-Side
Pilih section (Dashboard, Kecamatan, Jenis Ikan, Target). Charts → html2canvas → PNG. Tables → jsPDF autoTable
html2canvasjsPDFautoTable
3. Export PDF Server-Side
GET /export-pdf: Iktisar ringkasan, Tabel Kecamatan (split Pembesaran/Pembenihan), Target vs Realisasi
Server PDFautoTable
4. Filter-Aware Export
Semua export mengikuti filter aktif (tahun, kecamatan, dll). Hanya data terfilter yang di-export
Filter ParamsScoped Data
5. Download File
File dikirim sebagai attachment (.xlsx atau .pdf). Auto-naming dengan timestamp dan parameter filter
AttachmentAuto-Name

Disagregasi Data Agregat (Admin Only)
Pecah data agregat menjadi record individual per pembudidaya
1
Pilih Data Agregat
Pilih tahun, triwulan, kecamatan, jenis ikan, wadah, jenis usaha. Sistem mencari data agregat (totalQty) yang belum di-disagregasi
→
2
Preview Distribusi
Sistem menghitung distribusi proporsional berdasarkan RTP per kelompok pembudidaya. Tabel preview menunjukkan alokasi per individu
→
3
Simpan ke Database
Buat DisaggregationBatch + individual FishFarm records. Data agregat ditandai sudah diproses. Cache di-invalidate
